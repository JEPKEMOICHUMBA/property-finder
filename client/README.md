# Intelligent Property Finder with GIS Integration

A full-stack web application that helps users discover residential, commercial, and land properties using intelligent search, GIS visualization, and AI-powered property price prediction.

## Features

- User authentication
- Property listing management
- Advanced property search and filtering
- Interactive map visualization using OpenStreetMap
- AI-powered property price prediction
- Property recommendations
- Image upload for property listings
- Responsive user interface
- REST API backend

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Flask
- Python
- SQLAlchemy

### Database
- SQLite

### Machine Learning
- Scikit-learn
- Linear Regression

### GIS & Maps
- Leaflet.js
- OpenStreetMap
